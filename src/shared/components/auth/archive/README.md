# Archivo de Login y Registro Clásico (Magnus OS)

Este directorio conserva a resguardo la versión clásica de los componentes de autenticación previa a la modernización **Providence 2.0**.

- `Login.legacy.tsx`: Formulario de login original centrado con tarjeta monocromática y trofeo estándar.
- `Register.legacy.tsx`: Formulario de registro original.

Para restaurar o consultar la implementación anterior, estos componentes se mantienen funcionales y documentados.
